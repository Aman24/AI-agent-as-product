# Agent as Product

> **An AI agent is a product. The prompt is implementation.**
> Confusing the two is why most agent projects die in production.
> This repo is the framework for doing it right.

If you read one thing here, read **[The Agent Product Spec](./frameworks/ai-agent-product-spec.md)** — a seven-section framework for treating an AI agent as a product, not a prompt.
